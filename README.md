# Hate Speech Detection (NLP Sequence Classification)

This project implements an **NLP-based sequence classification model** designed to classify tweets into three categories:  
- **Hate Speech**  
- **Offensive Language**  
- **Neutral**  

The entire workflow — preprocessing, feature engineering, model training, and evaluation — is contained inside the Jupyter Notebook:  
`hate_speech_detection.ipynb`.

---

## Project Overview

With the growth of social platforms, toxic and abusive content has become increasingly common. Manual moderation at scale is impractical, making automated hate‑speech detection essential.

This project explores how Natural Language Processing (NLP) and machine‑learning techniques can classify social‑media text into harmful or harmless categories.  
The model is built specifically for **tweet classification** into the three categories above.

---

## Key Features

- **Text preprocessing** (cleaning, tokenization, normalization)
- **NLP sequence classification model**
- **Three‑class tweet categorization**: Hate Speech, Offensive, Neutral
- **Exploration-ready notebook format**
